🛡️ Movie Royal Backup Bots

Streamers see this backup as

This app runs Discord bots for Movie Royal streamers (yours and your friends') as a backup. It also reads each streamer's Twitch chat (live or offline) while their Movie Royal is closed, so the viewer profiles in Movie Royal keep counting chats and watch streaks (anyone in the viewer list or chatting while live watched that stream). Every minute it checks each streamer's 24/7 cloud bot. If the cloud bot has errors, this app answers /suggest, /swap, /mymovies, /list and /linktwitch with the same rules, until the streamer presses ☁️ Switch back to the cloud in their Movie Royal. If a streamer doesn't use the cloud bot, it answers whenever their Movie Royal is closed. While their Movie Royal is open, it stays quiet. Closing this window keeps it running in the tray by the clock.

💜 Twitch

Lets this app ask Twitch whether each streamer is live (for watch streaks: who's in the viewer list while you're live). Use the same Client ID and Secret as in Movie Royal (Settings → Twitch → Advanced: Twitch app keys), or make one at dev.twitch.tv/console/apps. One set works for every streamer's channel. Without it, this app uses Movie Royal's keys if Movie Royal is on this PC.

➕ Add a bot

Each streamer needs Movie Royal 1.27.0 or newer, opened once with their Discord bot on, so it makes the hidden #movie-royal-sync channel. A bot token gives full control of that bot: keep it private.
