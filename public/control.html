🚫 Banned movies

Banned movies can't be picked in Discord (people see them with a 🚫 so they know they spelled it right). Banning a movie that's already in the pool takes it out.

📅 New releases

Want to let one through anyway? Search it on the left and press Allow — or allow it below.

🎞️ Series rule

When someone picks a movie from a series (like Harry Potter or Lord of the Rings), nobody can pick another movie from that series while it's in the pool. This uses TMDB's "collection" info, so it works automatically.

Also blocked automatically

✅ Movies you've watched on Letterboxd · 🏆 movies that already won · 🔒 movies someone already picked — every movie can only be picked once.

Volume

Sound plays from the game screen, so OBS picks it up with the game window.

Make it yours

Every sound is built in. Press Upload next to any of them to use your own file instead (mp3, wav, ogg or m4a). Reset goes back to the built-in one. Changes are live — no restart.

Tip: Battle music and Countdown music loop, so pick a file that loops nicely.

📺 Preview window

A little window that shows what's on stream while you test. It comes back by itself when you open the 🧪 Test tab. ⧉ Pop out puts it in its own window you can drag to another monitor (no sound; Movie Royal already plays it). Close that window to bring it back here.

🔴 Pretend I'm live

Movie Royal acts like you just went live: streamer respins refill, voided spots come back, the movie count starts over, and it shows LIVE. It's fake: Twitch, Discord and your channel point rewards don't change. Press again to stop.

💬 Pretend chat

A small window where you type as any viewer: the battle winner claiming, “up” / “down” after a Move redeem, !respin, !sitout… It stays open on every tab (drag it by its top bar), and Movie Royal's replies show in it.

⚔️ Discord battle tests

Rule things out when balls don't come back. Not live? That doesn't matter: chat, the cliff and battles all work the same when you're offline.

💬 Pretend people type in chat (their movies join)

Try it: reset cooldowns → put everyone on the cliff → run a test battle → press Next round. If the balls come back, cooldowns were the reason they were missing (movies that won sit out for the week).

🔢 Number battle

Makes a battle where every ball is a number (it shows up as a new battle you can delete after).

🤖 Discord self-test

Checks everything about Discord that Movie Royal can check by itself: the bot, the channels, the pinned messages, the slash commands, who can see the debug channel, and the 24/7 bot. It runs the same code /suggest and /mymovies use, with a pretend user (nothing gets added). The results go to #movie-royal-debug too.

🛡️ Backup bot server

Checks the hidden #movie-royal-sync channel: Movie Royal leaves its notes there, and shows whether a Movie Royal Backup Bots app (yours or a friend's) is watching your bot. Add your bot with one click (the button below, or 🍿 Add my bot in the backup app). To test a takeover, press ▶ Run this bot now in the backup app, then try /mymovies in Discord with Movie Royal closed.

🐞 Discord debug channel

Posts a pretend problem in the hidden #movie-royal-debug channel (only mods and the server owner can see it).

📺 Every test here pops up a little window showing what's on stream right now, so you can see it (drag it by the top bar, resize it from a corner or edge).

💬 Pretend to be a chatter

Sends a fake Twitch chat message. Use someone's Twitch name to check them in, claim a win, answer roll call, or try !mymovies / !mymovies lucy.

🎬 Movie winner: claim, pass, pin, sit out

Pretend the movie winner is in chat. If no movie has won (or a wild spot won), Movie Royal makes a pretend winner from your Discord movies (it changes nothing). The 💬 Pretend chat window opens as the winner: type anything: Movie Royal asks the winner to type !accept or !pass (buttons here do it), and does what they answer. ✅ Accept / ⏭️ Pass on the winner card on the ⚔️ Battle tab are for doing it yourself.

⚡ Pretend channel points / bits

Fires a chaos event as if a viewer redeemed it. If no battle is running it gets queued for the next one, just like the real thing.

🎉 Pretend a ball power-up

Chat battle with power-ups on (🎲 Chat battle tab → Fun mode). Use the Twitch name of someone who joined.

🎬 Would Discord allow this movie?

Checks a title against every rule (watched, banned, this year, series, already in) without adding it.

Runs a round with made-up movies so you can see the countdown, fight, winner screen and sounds — try a big number to see how a huge chat battle looks. Your real lists, picks and history aren't touched.
